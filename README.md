# 💌 A Secret Message — I Didn't Write a Love Letter... I Coded One.

> *"I didn’t write a love letter… I coded one. 💻💓 A little HTML, CSS & JavaScript, a little creativity, and one secret message for someone special. 👀💌"*

An interactive, romantic web confession experience inspired by creative coding reels. Featuring ambient night sky canvas particles, typewriter effect confession letter, beating heart finale, audio companion with visualizer, and custom celebration animations.

🌐 **Live Deployed Site:** [https://sriteja2007.github.io/A-Message2/](https://sriteja2007.github.io/A-Message2/)

---

## ✨ The 3-Step Experience

### 1. 💌 The Secret Envelope (`#secret`)
- A floating glassmorphic card set against a starry cosmic twilight sky.
- Floating envelope icon with soft ambient lighting.
- Headline: **"A little secret..."**
- Subtext: *"I've been keeping something to myself. Maybe it's time you found out."*
- Action: Glowing gradient pill button **"Open My Heart 💖"** that unlocks ambient audio and triggers a burst of floating heart particles.

### 2. 📜 The Love Letter (`#letterSection`)
- An ivory parchment letter card with realistic stationery styling.
- Delicate overline: *"To someone who makes ordinary days feel different..."*
- Salutation: **"Dear You,"**
- **Typewriter Effect:** Types out letter text character-by-character with natural cadence pauses:
  > *I don't really know when it happened.*<br><br>
  > *Maybe it was one conversation.*<br>
  > *Maybe it was one smile.*<br>
  > *Maybe it was simply the way you became*<br>
  > *someone I started looking forward to.*<br><br>
  > *Some people enter your life quietly...*<br>
  > *and somehow become a favourite part of it.*<br><br>
  > *So this isn't a big confession.*<br>
  > *It's just a little piece of my heart,*<br>
  > *wrapped up in a webpage,*<br>
  > *because saying it directly is a little scary. 💗*
- Signature: *— From someone who secretly smiles because of you ♡*
- Fast-forward support: Tap anywhere on the letter to immediately complete typing.
- Button: **"One More Thing... ✨"** smoothly transitions to the grand finale.

### 3. 💖 The Grand Finale & Secret Kept (`#finaleSection`)
- Multi-layer pulsing neon heart with expanding concentric ripple rings.
- Large glowing statement:
  ```
  Maybe you're
  my favourite
  person.
  ```
- Subtitle: *"I don't know where this little story goes. But I know one thing... I'm really glad I met you."*
- Button: **"Keep this secret 🤫"**
- Romantic in-app secret confirmation modal: *"Okay... secret safely kept 🤫💗"*
- Massive 360° heart cannon celebration burst with 180+ physics particles and gold sparkle stars.
- Replay control: Easily restart the experience anytime.

## 🚀 Interactive Features

- **Ambient Canvas Physics:** 60fps HTML5 Canvas rendering twinkling stars, drifting translucent hearts with sine-wave sway, and streaking shooting stars.
- **Interactive Cursor Trail:** Mouse move and touch screen gestures leave a gentle fairy dust trail of mini hearts and sparkles.
- **Audio Companion with Equalizer:** Plays the soulful reel track with animated equalizer bars, mute/unmute toggle, and automatic browser autoplay unlock.
- **Ultra-Responsive:** Optimized for both mobile devices (9:16 vertical viewports like reels) and desktop displays.
- **Zero Heavy Dependencies:** Pure vanilla HTML5, CSS3, and JavaScript — lightning fast load times.

---

## 🛠️ Tech Stack

- **HTML5 & CSS3** (CSS Grid, Flexbox, Glassmorphism, CSS Custom Properties, Keyframe Animations)
- **JavaScript (ES6+)**
- **HTML5 Canvas 2D API** (Particle Physics, Vector Hearts, Shooting Stars)
- **Web Audio API** (Dual fallback / Autoplay gesture handler)
- **GitHub Actions & GitHub Pages** for automated CI/CD deployment

## 💻 Local Preview

Run any static HTTP server in the repository root:

```bash
# Python
python -m http.server 3000

# or Node / npx
npx serve .
```

Then visit [http://localhost:3000](http://localhost:3000) in your browser.
